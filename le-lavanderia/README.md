# Lê Lavanderia — Landing page

Landing page responsiva desenvolvida com HTML, CSS e JavaScript puro.

## Como visualizar
1. Extraia a pasta do projeto.
2. Abra `index.html` no navegador.
3. Para desenvolvimento, recomenda-se usar a extensão Live Server no Visual Studio Code.

## Estrutura
- `index.html`: conteúdo e estrutura semântica.
- `css/style.css`: identidade visual, layout e responsividade.
- `js/script.js`: menu mobile e ano automático no rodapé.

## Publicação gratuita no Netlify
1. Crie uma conta em https://www.netlify.com/.
2. Acesse https://app.netlify.com/drop.
3. Arraste a pasta do projeto (ou a pasta extraída) para a área indicada.
4. O Netlify publicará o site e fornecerá um endereço público.

## Antes de publicar oficialmente
- Confirme com a responsável se deseja divulgar o endereço residencial completo. A versão inicial mostra apenas Nova Vinhedo, Vinhedo - SP.
- Confirme se o horário das 8h às 18h vale para todos os dias de segunda a sábado, sem intervalo de atendimento.
- Revise os serviços e confirme quais peças/tecidos são aceitos para tingimento e lavagem especial.
- As imagens decorativas da primeira versão são ilustrações feitas em CSS; podem ser substituídas por fotos autorizadas da lavanderia ou das peças.
- O telefone e os links de WhatsApp estão configurados com o número informado.

## Tecnologias
HTML5, CSS3, JavaScript (Vanilla), Google Fonts.
